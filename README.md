# Hospitality Revenue Analysis – Power BI

## Project Overview

This project is an interactive Power BI dashboard designed to analyze hotel
revenue and booking performance.

The dashboard provides insights into revenue, occupancy, ADR, RevPAR,
realisation, cancellations, booking platforms and hotel performance.

## Business Objective

The objective of this project is to understand hotel performance and identify
areas that may require further business investigation.

## Key KPIs

- Revenue
- Occupancy %
- ADR (Average Daily Rate)
- RevPAR (Revenue per Available Room)
- Realisation %
- Cancellation %
- DSRN

## Key Insights

- Revenue showed a gradual increase during the analyzed period.
- Luxury hotels showed stronger revenue performance compared with business hotels.
- ADR remained relatively stable during the period.
- Weekday occupancy, particularly for business hotels, requires further investigation.
- Cancellation and no-show patterns may be affecting room utilisation.
